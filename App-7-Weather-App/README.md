#What is this project?
This gives graph of weather graph and sky information . its made using stream lit

It has 2 files 
-main.py
  Which has frontend code using streamlit 
-backend.py
 Which has backend logic , basically a function which calls data from a open source weather APi
 that function is imported into main.py

The app gives the temperature graph for a particular city with in specific number of days upto 5 days.
The temperature is displays in Degree Celsius on a graph and the sky conditions are displayed using Images .
The conditions are like Clear, Rain, cloud, snow
